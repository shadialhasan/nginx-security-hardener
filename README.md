# 🔒 nginx-security-hardener

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Security: Mozilla Modern](https://img.shields.io/badge/Security-A%2B%20SSL%20Grade-brightgreen.svg)](https://github.com/MobileConduit)

An automated Nginx virtual host generator enforcing modern cryptographic standards (TLS 1.3, HSTS Preload, buffer overflow mitigation, clickjacking deterrence, and strict Content-Security-Policy).

```bash
python hardener.py --domain api.exclusive-identity.net --port 8000
```
